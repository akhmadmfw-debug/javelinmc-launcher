OPTIFINE НА ВСЕ ВЕРСИИ — быстрый способ
=======================================
Скачивать по одному с сайта не надо. Один скрипт берёт СВЕЖИЙ OptiFine
для каждой версии Minecraft сразу (сейчас это 42 версии: от 1.7.2 до 1.21.11).


ШАГ 1. СКАЧАТЬ ВСЁ
------------------
Открыть папку C:\Users\akhma\Desktop\JavelinMC в проводнике,
в адресной строке набрать  cmd  и Enter, затем выполнить:

    node скачать-optifine.js

Скрипт скачает по одному лучшему файлу на версию в папку
    C:\Users\akhma\Desktop\JavelinMC\optifine-jars

Идёт пару минут (пауза между файлами, чтобы сайт не ругался).
Уже скачанные файлы при повторном запуске пропускаются.


ШАГ 2. ЗАЛИТЬ В РЕЛИЗ
---------------------
Способ А (мышкой, надёжно):
  1. Открыть  https://github.com/akhmadmfw-debug/javelinmc-mods/releases/new
  2. Choose a tag -> вписать  optifine  -> "Create new tag: optifine on publish"
  3. Title:  OptiFine
  4. Перетащить в поле загрузки ВСЕ файлы из папки optifine-jars
  5. Дождаться галочек -> Publish release

Способ Б (одной командой, если стоит GitHub CLI "gh"):
    gh release create optifine optifine-jars/*.jar -t OptiFine -R akhmadmfw-debug/javelinmc-mods
  (если релиз optifine уже есть — заменить create на upload)


ШАГ 3. ГОТОВО
-------------
Перезапусти лаунчер, нажми на бирку версии. У КАЖДОЙ версии, где есть и
OptiFine, и Forge, появится чип OPTIFINE. Нажал -> лаунчер сам ставит
Forge нужной версии и кладёт OptiFine в моды этой сборки.

Это и есть связка Forge+OptiFine. Отдельно её включать не надо — она сама
появляется там, где есть оба.


ЕСЛИ ВЫШЛА НОВАЯ ВЕРСИЯ OPTIFINE
-------------------------------
Просто снова запусти  node скачать-optifine.js  и дозалей новые файлы в тот
же релиз. Старые скрипт не перекачивает.


ВАЖНО ПРО ЛИЦЕНЗИЮ
------------------
Лицензия OptiFine запрещает распространять их jar-файлы. Раздача через твой
GitHub-релиз идёт под твою ответственность как владельца репозитория.
Технически всё работает; юридически — решение за тобой.
