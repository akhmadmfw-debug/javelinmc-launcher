# Как собрать установщик для macOS

Собрать `.dmg` на Windows невозможно — для этого нужны инструменты самой macOS.
Мак покупать не надо: у GitHub есть бесплатные маковские машины, и всё уже
настроено. Ниже — что нажать.

**Windows-версия при этом ничего не меняет:** она как собиралась здесь командой
`npx electron-builder`, так и собирается, со встроенной Java внутри.

---

## Один раз: подготовка

### 1. Отправить исходники на GitHub

В папке проекта уже создан репозиторий git и настроен `.gitignore`, поэтому
лишнее (встроенная Java на 305 МБ, склад OptiFine на 188 МБ, `config.json`
с ключом, старые копии) на GitHub НЕ уйдёт. Уходит 30 файлов, 9.5 МБ.

```bash
git commit -m "Исходники лаунчера + сборка для macOS"
```

```bash
git remote add origin https://github.com/akhmadmfw-debug/javelinmc-launcher.git
```

```bash
git branch -M main && git push -u origin main
```

Если git попросит имя и почту — задай их один раз:

```bash
git config --global user.name "SanjiKune" && git config --global user.email "feras1960@gmail.com"
```

### 2. Положить config.json в секрет

`config.json` в репозиторий не уходит — в нём ключ CurseForge, а репозиторий
открытый. Вместо этого он берётся из секрета:

1. Открой `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
2. Имя: **`JV_CONFIG`**
3. Значение: **всё содержимое файла `config.json`** — открой его блокнотом,
   выдели всё, скопируй и вставь.
4. `Add secret`

---

## Каждый раз: собственно сборка

1. Вкладка **Actions** в репозитории
2. Слева — **«Сборка для macOS»**
3. Кнопка **Run workflow** → **Run workflow**
4. Ждать ~8 минут
5. Внизу страницы сборки — блок **Artifacts**, там `JavelinMC-macOS`.
   Скачиваешь, внутри два файла:
   - `JavelinMC-1.0.45-x64.dmg` — для маков на Intel
   - `JavelinMC-1.0.45-arm64.dmg` — для маков на Apple Silicon (M1/M2/M3/M4)

Итого два установщика:

| Система | Файл | Где собирается |
|---|---|---|
| Windows | `JavelinMC-Setup-1.0.45.exe` | у тебя, `npx electron-builder` |
| macOS | `JavelinMC-1.0.45-x64.dmg` и `-arm64.dmg` | GitHub, кнопкой |

## Что игрок увидит на маке

Приложение **не подписано** сертификатом Apple (это 99 $ в год, мы решили
не брать). Поэтому при **первом** запуске macOS не даст открыть его двойным
щелчком. Игроку надо один раз сделать так:

> Правая кнопка по значку JavelinMC → **Открыть** → в окошке ещё раз **Открыть**

Дальше приложение открывается обычным способом. Ровно так же работают почти все
сторонние лаунчеры Minecraft. Эту строчку стоит написать рядом со ссылкой на
скачивание.

**Java игрок скачивать не должен** — лаунчер при первом запуске игры сам
загрузит нужную (36 МБ на Intel, 41 МБ на Apple Silicon) и запомнит её.

## Если сборка упала

- **«Не задан секрет JV_CONFIG»** — не сделан шаг 2 выше.
- **`npm ci` ругается** — значит `package-lock.json` не попал в репозиторий.
  Проверь, что он есть на GitHub.
- Всё остальное видно прямо в логе сборки: жми на упавший шаг, там написано.
