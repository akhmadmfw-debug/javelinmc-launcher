# Встроить Java в лаунчер (чтобы игрокам ничего не ставить)

Цель: игрок скачивает один `.exe`, ставит, заходит — и играет. Java и authlib-injector уже внутри.

---

## Шаг 1. Скачать Java 17 (портативную, .zip)

1. Зайди: **https://adoptium.net/temurin/releases/?version=17&os=windows&arch=x64&package=jre**
2. Скачай файл **`.zip`** (Package Type: **JRE**, Architecture: **x64**, Version: **17**).
   - Нужен именно **.zip**, не .msi (нам нужна папка, а не установка).

## Шаг 2. Сделать папку `runtime` в проекте

1. Распакуй скачанный .zip.
2. Внутри будет папка вида `jdk-17.0.19+10-jre` (с папками `bin`, `lib` и т.д.).
3. **Переименуй эту папку в `runtime`** и положи её в `JavelinMC`.
4. Проверь, что путь существует:
   ```
   C:\Users\akhma\Desktop\JavelinMC\runtime\bin\javaw.exe
   ```
   Если `runtime\bin\javaw.exe` есть — всё правильно.

> Важно: внутри `runtime` должна сразу быть папка `bin` (а не ещё одна вложенная папка `jdk-17...`). Если получилось `runtime\jdk-17...\bin` — зайди внутрь и подними содержимое на уровень выше.

## Шаг 3. Проверить authlib-injector

Файл должен называться **ровно** `authlib-injector.jar` и лежать в папке `JavelinMC` (не полный путь, просто имя). В новом `config.json` уже указано `"authlibInjector": "authlib-injector.jar"`.

## Шаг 4. Обновить файлы

Скачай из чата и замени в папке `JavelinMC`:
- `main.js`
- `package.json`
- `config.json`

## Шаг 5. Собрать установщик

В папке `JavelinMC` → `cmd`:
```
npm run dist
```

Теперь в установщик попадут и **Java**, и **authlib-injector**. Файл `dist\JavelinMC Setup 1.0.1.exe` можно давать любому игроку — у него заработает **без установки Java**.

---

## Что теперь у игрока

1. Скачал `JavelinMC Setup 1.0.1.exe`.
2. Запустил (SmartScreen → «Подробнее» → «Выполнить всё равно»).
3. Установился, открыл лаунчер.
4. Капча → «Аккаунт» → регистрация → «Играть» → вход Ely.by.
5. Игра скачивается и запускается. **Java ставить не нужно — она внутри.**

---

## Важно про версии

Встроенная Java 17 подходит для Minecraft **1.17–1.20.4** (у тебя 1.20.1 — ок).
Если переедешь на **1.21+** — нужно будет вложить **Java 21** (тем же способом, скачав Java 21 вместо 17).

## Не забудь про сервер

Чтобы игрок реально зашёл на сервер, на **сервере** должен стоять authlib-injector:
`-javaagent:authlib-injector.jar=ely.by` + `online-mode=true` (см. `ИНСТРУКЦИЯ-ElyBy.md`).
