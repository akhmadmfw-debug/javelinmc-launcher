# JavelinMC — переход на вход через Ely.by (бесплатно, без покупки Minecraft)

Теперь игроки заходят через бесплатный аккаунт **Ely.by**, а не через Microsoft. Каждый игрок один раз регистрируется на **https://ely.by** (бесплатно), и потом вводит этот логин/пароль в лаунчере — Minecraft покупать не нужно.

Это законно: Ely.by — официальная сторонняя система аккаунтов. Каждый игрок защищён паролем, чужой ник занять нельзя.

---

## Что обновить в твоей папке JavelinMC

1. **Заменить** файлы новыми версиями:
   - `main.js`
   - `config.json`
   - `package.json`
2. **Добавить** два новых файла (просто положить в папку):
   - `ely-login.html`
   - `ely-preload.js`
3. Остальные файлы (`javelinmc-launcher.html`, `preload.js`, `electron-glue.js`) — без изменений.

Переустанавливать библиотеки **не нужно** (`npm install` повторно делать не требуется).

---

## Шаг 1. Скачать authlib-injector (обязательно)

Это маленькая библиотека, без неё вход через Ely.by не сработает.

1. Зайди на **https://github.com/yushijinhun/authlib-injector/releases**
2. Скачай самый свежий файл вида `authlib-injector-X.X.X.jar`.
3. **Переименуй его в `authlib-injector.jar`** и положи в папку JavelinMC (рядом с `main.js`).

> Если не хочешь переименовывать — впиши настоящее имя файла в `config.json` в поле `"authlibInjector"`.

---

## Шаг 2. Проверить config.json

Открой `config.json` и убедись, что заполнен свой сервер и есть строка про authlib:

```json
{
  "serverIp": "play.javelinmc.net",
  "serverPort": 25565,
  "version": "1.20.1",
  "type": "release",
  "ram": 4,
  "forgeInstaller": "",
  "authlibInjector": "authlib-injector.jar"
}
```

---

## Шаг 3. Запуск и вход

1. В папке открой командную строку (`cmd` в адресной строке) и запусти:
   ```
   npm start
   ```
2. Нажми **«Играть»** → откроется маленькое окно входа Ely.by.
3. Введи свой логин и пароль Ely.by (если аккаунта нет — кнопка регистрации ведёт на ely.by).
4. Игра скачается, запустится и сама зайдёт на твой сервер.

---

## Шаг 4. Настройка СЕРВЕРА (важно!)

Чтобы сервер пускал игроков Ely.by, на **сервере** тоже нужен authlib-injector:

1. Скачай тот же `authlib-injector.jar` и положи в папку сервера.
2. В команду запуска сервера добавь `-javaagent` **перед** `-jar`:
   ```
   java -Xmx4G -javaagent:authlib-injector.jar=ely.by -jar server.jar nogui
   ```
3. В файле `server.properties` оставь:
   ```
   online-mode=true
   ```
   authlib-injector сам перенаправит проверку на Ely.by — так сервер защищён, и никто не зайдёт под чужим ником.

> Если у тебя связка через BungeeCord/прокси — настройка чуть другая, см. официальную инструкцию Ely.by: https://docs.ely.by/ru/authlib-injector.html

---

## Если что-то не так

- **«Не найден authlib-injector.jar»** — файл не лежит в папке лаунчера или назван иначе. Проверь Шаг 1.
- **«Неверный логин или пароль Ely.by»** — проверь данные аккаунта на ely.by (логином может быть и e-mail, и ник).
- **Заходит в игру, но кикает с сервера** — значит на самом сервере не настроен authlib-injector (Шаг 4) либо `online-mode` стоит неверно.

Если будет ошибка — пришли мне её текст из командной строки, помогу. 👍
